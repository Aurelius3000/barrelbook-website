# Bar Display for Alice’s local collection

The feature lives in the collection web app on the local `codex/bar-display` worktree. The emulator launcher enables it for the existing `demo-barrelbook-web` fixture. The working preview uses [port 4187](http://127.0.0.1:4187).

Sign in as local Alice, choose **Bar Display**, preview the selected shelf, set a six-digit PIN and start the display. The owner’s existing session ends at handoff. End the display with its PIN and sign in again to open the owner workspace.
