# Design Notes

The page uses BarrelBook's existing dark visual system and makes no Android-download claim. Primary copy is “BarrelBook for Android is in the works.” The lone action is “Continue to Google Form.” The existing iOS App Store badge remains the primary download action on the homepage; the Android path is secondary text so it cannot confuse iOS acquisition or attribution.

The website does not contain an email form. It hands the visitor to the published Google Form, which is owned by `pete@petereilly.com` and asks only for email, 21+ confirmation, and consent. It does not collect a name, device identifier, collection data, or free-text research data.
